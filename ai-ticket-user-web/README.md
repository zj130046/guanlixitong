# AI 智能客服用户端

普通用户咨询、FAQ 查询、工单创建与满意度评价前端。

## 技术栈

- Vue 3
- TypeScript
- Vite
- Axios
- Element Plus
- Pinia

## 本地开发

```bash
npm install
npm run dev
```

默认端口：`5173`

后端 API 默认地址：`http://localhost:8080/api`，可在 `.env.local` 中通过 `VITE_API_BASE_URL` 覆盖。

## 脚本

```bash
npm run dev      # 启动开发服务器
npm run build    # 类型检查并构建生产包
npm run preview  # 预览构建结果
```
