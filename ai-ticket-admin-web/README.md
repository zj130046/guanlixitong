# AI 智能客服管理后台

管理员配置账号、工单规则、FAQ 知识库、统计报表和系统参数前端。

## 技术栈

- Vue 3
- TypeScript
- Vite
- Axios
- Element Plus
- Pinia

## 本地开发

```bash
npm install
npm run dev
```

默认端口：`5175`

后端 API 默认地址：`http://localhost:8080/api`，可在 `.env.local` 中通过 `VITE_API_BASE_URL` 覆盖。

## 脚本

```bash
npm run dev      # 启动开发服务器
npm run build    # 类型检查并构建生产包
npm run preview  # 预览构建结果
```
