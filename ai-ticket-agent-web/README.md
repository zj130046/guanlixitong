# AI 智能客服坐席端

客服接单、处理、人工会话、超时预警和主管督办前端。

## 技术栈

- Vue 3
- TypeScript
- Vite
- Axios
- Element Plus
- Pinia

## 本地开发

```bash
npm install
npm run dev
```

默认端口：`5174`

后端 API 默认地址：`http://localhost:8080/api`，可在 `.env.local` 中通过 `VITE_API_BASE_URL` 覆盖。

## 脚本

```bash
npm run dev      # 启动开发服务器
npm run build    # 类型检查并构建生产包
npm run preview  # 预览构建结果
```
